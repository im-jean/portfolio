# Portafolio Personal — Jean Somarriba

Sitio web personal desarrollado desde cero para presentar mi historia, proyectos y evolución como desarrollador.

## Tecnologías utilizadas
* **HTML5:** Estructura semántica.
* **CSS3:** Variables personalizadas (`:root`), Flexbox, anidamiento nativo y diseño oscuro.

## Estructura del proyecto
* `index.html` — Página principal.
* `css/` — Hojas de estilo y variables de diseño.
* `img/` — Recursos gráficos y foto de perfil.
* `proyectos/` — Proyectos y prácticas destacadas.

## Estado del proyecto
🚧 En desarrollo activo — Actualmente trabajando en las secciones de Proyectos, Habilidades y adaptación móvil (*Responsive Design*).
